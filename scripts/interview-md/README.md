## 文件说明

| 文件 | 用途 |
|---|---|
| `<文件名>.md` | 已入库的 Markdown 题目文件，每份对应一个主题 |
| `转换报告.md` | 每份 PDF 的解析模式、题数、空答案、样例 |
| `校验报告.md` | 按导入规则校验：题数、空答案、超长内容、文件大小 |
| `校对清单.csv` | 转换时 768 道题的清单（修复拆标题后为 744 题） |
| `convert_pdfs.py` | 转换脚本（PyMuPDF + 规则解析） |
| `validate_md.py` | 校验脚本 |

## 已知限制 / 校对建议

1. **讲义类 PDF**（常见集合、JVM、多线程、设计模式）按章节/小节标题转为题目，答案偏长，属于「主题 + 完整讲解」；
2. PDF 中的代码块、页码、代码行号已丢弃，依赖代码示例的答案可能不完整；
3. 原 PDF 中 33 题无参考答案：24 题为拆标题碎片，已于 2026-11-13 合并删除；剩余 9 题已补写，当前空答案为 0；
4. PDF 文本层可能有少量错字或多余空格，建议按 `校对清单.csv` 抽查；
5. 部分陈述式标题（如「时间复杂度」）可按需改写为问句。

## 重新导入注意

导入接口按「预览 token」去重，重复上传同一文件会产生新的一批题目。
如需重新导入某个文件，请先在面试题库中删除该主题下的旧题（或按 `source_doc_name` 清理），再重新导入。

## 重跑方式

```bash
python -m pip install pymupdf
python scripts/interview-md/convert_pdfs.py "<PDF目录>" "scripts/interview-md" "scripts/interview-md/转换报告.md"
python scripts/interview-md/validate_md.py "scripts/interview-md" "scripts/interview-md/校对清单.csv" "scripts/interview-md/校验报告.md"
```
