## 2. 生产部署

新增文件：

| 文件 | 用途 |
|---|---|
| `deploy/Dockerfile.backend` | 多阶段构建 Spring Boot 镜像（Maven → JRE 17） |
| `deploy/Dockerfile.web` | 构建学员端 + 管理端，Nginx 统一托管 |
| `deploy/nginx.conf` | `/` 学员端、`/admin/` 管理端、`/api/` 后端（SSE 关闭缓冲）、`/files/` MinIO |
| `deploy/docker-compose.prod.yml` | MySQL + Redis + MinIO + 后端 + Web 完整生产栈 |
| `deploy/env/.env.prod.example` | 生产密钥模板 |
| `deploy/README.md` | 部署、HTTPS、备份、升级与安全清单 |

要点：

- 仅暴露 Web 端口（默认 8088），数据库/缓存/对象存储仅内网；
- `PREVIEW_PORTAL_LOGIN_ENABLED=false`，生产禁用内测免登录；
- Swagger 通过环境变量关闭；
- `MINIO_PUBLIC_URL=/files`，由 Nginx 反代到 MinIO；
- 首次启动自动执行 `scripts/sql/schema.sql`。

快速启动：

```bash
cp deploy/env/.env.prod.example deploy/.env
docker compose -f deploy/docker-compose.prod.yml up -d --build
```
