# AI 提示词模板

`ai` 模块统一读取本目录下的提示词模板，模型调用细节不外泄到业务模块（02 §2.2）。

按设计需准备三套模板（实施时补充）：

| 文件 | 用途 | 依据 |
|---|---|---|
| `short-answer-grading.md` | 简答批改：按「关键点」命中率给 0–10 分，≥6 通过 | 需求 3.5、G4 |
| `interview-question-score.md` | 面试逐题评分：0–10 分 + 评语，SSE 流式输出 | 需求 3.8.2、04 §2.9 |
| `interview-report.md` | 整场汇总：六维度分数 + 优缺点 + 改进建议 + 三张提升卡 | 需求 3.8.3、G1 |

约定：

- 模板中的变量使用 `{{variable}}` 占位，由 `ai` 模块填充；
- 要求模型输出结构化 JSON，服务端做容错解析；
- 模型超时/失败时降级（简答退化为关键词规则判分，面试返回模拟评分并明确提示），
  不静默失败（02 §2.5、R1）；
- 提示词随代码版本管理，不落数据库。
