# 云枢智学 · 可交互页面原型

基于 `docs/云枢智学-需求文档.md`（v1.1，587 行）做的纯前端原型：**只验证交互与信息结构，不接服务端**。
打开 `index.html` 即可使用，没有构建步骤、没有依赖、没有网络请求。

> 语音转文字调用浏览器 Web Speech API（Chrome / Edge），需要麦克风权限。`file://` 下部分浏览器会拒绝麦克风，**建议用下面的本地服务方式打开**，识别更稳定。

## 怎么打开

- 直接双击 `index.html`（推荐 Chrome / Edge）
- 或在 `prototype/` 下起任意静态服务，例如：
  ```bash
  python -m http.server 8080
  ```
  然后访问 `http://localhost:8080`（语音识别建议用这种方式）

## 演示入口

| 入口 | 说明 |
|---|---|
| `index.html` | **身份选择页**：学生端 / 管理端 |
| 学生端卡片 | 进入学员端首页 `#/home`（演示账号已登录） |
| 首页右上角头像 | 个人中心 / 我的错题 / 面试记录 / 退出 |
| 管理端卡片 | 进入后台登录页，账号 `admin`，密码 `admin123` |
| 页脚「切换身份」 | 回到身份选择页 `#/` |
| `index.html#/admin/dashboard?demo=1` | 跳过后台登录直进看板（评审用） |

演示数据全部为虚构；练习会话存在浏览器本地（`localStorage`，再次进入会提示「继续 / 重新开始」），面试会话只在本次页面会话内保留，刷新后需重新开始。

## 覆盖的页面

**入口页（1）**：身份选择（学生端 / 管理端）。

**学员端（13）**：首页、登录、注册、找回密码、学习路线、题库中心、刷题练习、错题本、面试配置、面试进行中、面试报告、面试记录、个人中心。

**管理端（12）**：后台登录、数据看板、学科管理、B站课程库、题库管理、面试题库管理、学习路线（列表 + 详情）、学员管理、用户管理、角色管理、操作日志、系统设置。

## 可以点的交互

- **身份选择页**：打开 `index.html` 先看到两张入口卡（学生端 / 管理端），点击进入对应系统；学员端与管理端账号体系独立
- **首页**：首屏 4 项数据、快速开始 4 入口、新手引导（首次访问，三步弹窗）
- **注册/登录**：两种登录方式切换、验证码 60 秒倒计时、密码强度条、协议勾选拦截、找回密码三步
- **题库**：学科切换、阶段列表、题型/难度/关键词筛选、单题解析弹窗、按阶段或按题开始练习
- **练习**：顺序/随机模式选择、计时器、答题卡跳题与状态色、单选/多选/判断即时判分、简答 AI 评分动画与要点命中、解析、结束练习二次确认、未完成练习续做提示、`← → Enter ?` 快捷键
- **错题本**：四张统计卡、高频错题 Top3、状态筛选、勾选批量操作、标记已掌握、移除、重做
- **学习路线**：8 个学科切换、路线头与统计（课程数 / 总时长 / 已完成）、课程列表、「去B站学习」新标签打开；每门课可勾选「标记完成」，计入已学课程
- **AI 面试**：方向/难度/题数配置、剩余次数、逐题对话与评分、侧边栏题目与统计、本题 5 分钟倒计时、输入区**真实语音转文字**（浏览器语音识别，实时转写进输入框）、结束生成报告
- **面试报告**：环形综合分、六维度卡、优缺点、改进建议、能力提升卡、历史记录
- **管理端**：学科增删改与阶段上下移、课程新增/编辑（多学科、bvid、简介、上下架）/批量导入解析预览、题库审核状态流转（通过/驳回/上下架/重新提交）与批量操作、面试题录入与编辑（按方向归属）、路线课程排序与添加、学员详情抽屉与导出、角色权限树（9 组 35 项）、日志详情与清空、系统设置保存

## 设计说明

- **方向**：纸感底座 + 深墨文字 + 玉青强调。学员端像一本课程手册（衬线标题、大号等宽数字），管理端换成深墨侧栏，两端口吻区分。
- **令牌**：颜色、圆角、阴影集中在 `app.css` 的 `:root`，改一处即全站生效。
- **响应式**：≥1080 三列、760–1080 两列、<760 单列并收拢导航。

## 尚未覆盖（按需求文档，原型不验证）

- 真实登录鉴权、接口频控、失败锁定等安全策略（只做了交互提示，阈值未模拟）
- docx/pdf 解析、Excel 真实导入导出（弹窗与解析预览为模拟）
- 语音播报只做状态切换与提示；语音识别依赖浏览器 Web Speech API（Chrome / Edge + 麦克风权限，部分浏览器在 `file://` 下会拒绝）
- 面试回放（弹窗为占位）
- 数据看板 30/90 天为模拟曲线，非真实统计
